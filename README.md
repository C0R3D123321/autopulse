# AutoPulse

Локальная PWA — журнал обслуживания автомобиля. Данные и копии фотографий хранятся в IndexedDB на устройстве; сервер раздаёт только файлы приложения.

## Запуск

Раздайте папку статическим HTTP-сервером (например, `python -m http.server 4173`). Для service worker требуется HTTPS или localhost.

## Локальные данные

Настройки машины, сервисная история и сжатые копии изображений сохраняются в IndexedDB. Оригинал из галереи не нужен. Резервная копия: настройки профиля → Экспорт / Импорт (JSON с фотографиями).

Визуальный стиль использует шрифт Google Fonts при наличии сети и системные fallback-шрифты без неё.

## GitHub Pages

Workflow `.github/workflows/deploy-pages.yml` публикует веб-файлы при пуше в `main`. В Settings → Pages выбран источник GitHub Actions. Все пути относительные, поэтому приложение работает в `/autopulse/`.

На iPhone: открыть адрес в Safari → Поделиться → На экран «Домой».
При переезде с другого домена сначала экспортируйте данные на старом сайте, затем импортируйте на новом. Данные разных доменов автоматически не переносятся.

## Мобильная вёрстка

Onboarding использует `100dvh`, safe-area и закреплённую нижнюю кнопку. На коротких экранах уменьшаются отступы и заголовки. При открытой клавиатуре или увеличенном системном шрифте центральная область может прокручиваться, кнопка остаётся доступной. Основной график и история прокручиваются с запасом под нижнее меню.

Проверка: `node tests/mobile.cjs` (Playwright должен быть установлен или доступен через `NODE_PATH`).
